# 9. Decisiones

Resumen de las decisiones de arquitectura. El detalle de cada una está en [Decisiones (ADR)](../decisiones/index.md).

| ADR                                                                  | Decisión                                                          | Estado   |
|----------------------------------------------------------------------|-------------------------------------------------------------------|----------|
| [0001](../decisiones/0001-arquitectura-en-capas.md)                  | Arquitectura en capas con repositorios y servicios                | Aceptada |
| [0002](../decisiones/0002-dos-roles.md)                              | Solo dos roles (Administrador y Técnico), controlados por middleware | Aceptada |
| [0003](../decisiones/0003-borrado-logico.md)                         | Borrado lógico en todas las tablas                                | Aceptada |
| [0004](../decisiones/0004-stock-por-movimientos.md)                  | El stock solo cambia con movimientos                              | Aceptada |
| [0005](../decisiones/0005-precios-en-servidor.md)                    | Precios y totales calculados en el servidor                       | Aceptada |
| [0006](../decisiones/0006-web-y-api-separadas.md)                    | Interfaz web y API REST como dos entradas separadas               | Aceptada |
